# LinguaGo

A gamified English learning mobile app for beginners to intermediate learners.
Short daily lessons, vocabulary, grammar, listening, speaking practice, streaks and XP.

## Features
- Onboarding with placement test
- Learning path with lessons and quizzes
- Vocabulary flashcards with spaced repetition
- Grammar rules and exercises
- Listening and pronunciation practice
- Streaks, XP, badges and progress stats
- AI conversation partner (planned)

## Tech stack
- Flutter (Dart), Riverpod, go_router
- Firebase (Auth, Firestore, Storage)
- UI designed with Google Stitch, built with Google Antigravity

## Getting started
1. Install Flutter
2. `git clone https://github.com/<your-username>/linguago-app.git`
3. `cd linguago-app`
4. `flutter pub get`
5. `flutter run`
